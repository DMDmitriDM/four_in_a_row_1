### Игра 4 в ряд (сборка Webpack).
* Игра с компьютером.

* Цель игры – первым заполнить 4 квадратика своего цвета в один ряд (по горизонтали, по вертикали или по диагонали).
Игрок - оранжевым, компьютер - зелёным.
Победит тот, кто первым выложит непрерывный ряд из четырёх квадратиков по горизонтали, вертикали или диагонали.

* В начале игры нужно бросить кубики на право первого хода.

* Игроку или компьютеру для того, чтобы заполнить квадратик своим цветом необходимо сначала бросить кубики.
Затем сложить выпавшие числа и выбрать квадратик с этим результатом.
Например: Если выпало 3 и 4, то квадратик для заполнения 7.

### Необходимые требования
node.js версия не ниже 22.12.0
npm версия не ниже 10.9.0
При необходимости установить serve
npm install --global serve

### Установка и запуск проекта
1. Склонируйте данный репозиторий к себе на диск.
2. Из директории four_in_a_row_1 выполните команду `npm i` для установки
и `npm run dev` для запуска проекта в режиме отладки.
Затем откройте браузер по адресу http://localhost:8080/.

3. Для создания продакшен проекта остановите сервер отладки командой CTRL+C
(если он был запущен).
4. Из директории four_in_a_row_1 выполните команду `npm run build`.
5. Из директории dist выполните команду `npx serve`.
Затем откройте браузер по адресу http://localhost:3000/.
